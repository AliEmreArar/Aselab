# Caption deneyi sunumu

Güncel sunum: **Caption_Deneyi_Sunum_Tam_Caption.pptx** (4 slayt).

İkinci slaytta 170623.jpg örneğinin orijinal caption'ının tamamı ve kısa, dengeli, gündelik varyantları gösterilir. PowerPoint konuşmacı notları yöntemi, kaynakları ve değerlendirme sınırlarını içerir.

Kısa anlatım ve soru-cevap rehberi: **SUNUM_KONUSMA_NOTLARI.md**.

`Caption_Deneyi_4_Slayt.pptx` ve `Caption_Deneyi_Sunum.pptx` önceki sürümlerdir. Sunum için güncel dosyayı kullanın.

Yeniden üretim kaynağı: `.presentation-build/caption_bulgular/build.mjs`. Script yerel Codex sunum çalışma ortamını gerektirir. Geçici taslaklar, önizlemeler, doğrulama kayıtları ve runtime bağlantıları repoya dahil edilmez.
